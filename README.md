# 东南大学选课助手

一个面向东南大学选课页面的 Tampermonkey userscript。仓库保留了历史稳定脚本，并包含正在重构的 TypeScript 实验版。

> 维护状态：Greasy Fork 上的 v3.4.0 是最后一个在作者实际使用环境中验证过的版本。v4 已完成工程化重构和自动化测试，但尚未在当前本科或研究生选课系统中进行真实验证。请勿在正式选课时段直接使用 v4，也请遵守学校的选课规定。

## 历史稳定版（v3）功能

以下内容描述旧版脚本的实际功能，用于帮助使用者理解，也作为 v4 回归测试的行为基线。

### 添加待选课程

- 在课程详情展开后，为教学班显示“添加”按钮；点击后将该教学班加入待选列表。
- 支持在脚本面板中输入“8 位课程号 + 教学班序号”。多个编码可用空格分隔。
- 已成功加入的课程不会重复添加；当前页面找不到或教学班序号不匹配的编码会保留在输入框中。
- 待选列表显示课程名、教师，并可查看课程详细信息或删除课程。

### 自动搜索

当输入的课程不在当前页面，且启用自动搜索时，脚本会按下列顺序分页搜索：

```text
推荐课程 → 方案内课程 → 方案外课程 → 体育项目 → 通选课
```

搜索到匹配的课程号和教学班序号后会立即加入待选列表。每页数量和翻页延迟可配置；旧版默认每页 20 条、间隔 500 ms。

### 提交模式

脚本支持以下组合：

| 配置 | 含义 |
| --- | --- |
| 单次 / 循环 | 完成列表一轮后结束，或继续尝试剩余课程 |
| 同步 / 异步 | 每轮等待响应后计时，或按时间间隔直接发出下一轮 |
| 单个 / 分组 | 每轮提交 1 门，或并行提交最多 3 门 |

四种“发送模式 × 发送方式”组合可分别设置间隔。提交成功的课程会从待选列表删除；失败的课程会保留。运行期间不能编辑课程列表或设置，但可以通过“停止抢课”结束后续调度。

## v4 实验版

v4 保留旧版的核心用户行为，同时将实现拆分为可维护、可测试的模块：

- TypeScript 类型：课程、设置、页面数据与接口响应。
- 原生 `fetch`、`URLSearchParams` 和 `AbortController`：不再依赖页面注入的 Axios/Qs，并能停止在途请求。
- 可追踪的调度器：网络错误后恢复状态，避免异步慢响应导致重复提交。
- Lit + Shadow DOM：脚本面板样式与学校页面隔离。
- 独立页面适配层：课程详情 DOM 改动时只需修改一个模块。
- v3 本地待选课程迁移；不再长期存储 token。

完整的旧版行为契约见 [`docs/legacy-behavior-spec.md`](./docs/legacy-behavior-spec.md)。其中列出了接口、页面交互、已知旧 bug 和后续差分测试清单。

### 本地构建与测试

需要 Node.js 22 或更高版本。

```bash
npm install
npm run build
npm test
```

构建产物为 `dist/grab-lessons-for-seu.user.js`，即单个可安装的 userscript 文件。`dist/` 不纳入 Git；它不是 Greasy Fork 自动发布源。

当前自动化测试覆盖课程解析、旧数据迁移、`301` 确认请求、失败恢复、异步分组调度和课程详情按钮注入。它们不能代替真实选课系统的兼容性验证。

## 参与维护

仍在使用该系统的同学如发现页面或接口变化，欢迎提交 Issue 或 Pull Request。反馈时请提供脱敏后的页面 DOM 片段、控制台报错或请求结构；**不要**提交登录凭据、token、`secretVal`、课程表或任何个人选课数据。

在提交代码前，请运行：

```bash
npm run build
npm test
```
